# 걷고 보다

전국의 국가유산 답사기와 박물관 전시 관람기를 올리는 블로그입니다.

- **글** — `content/posts/*.md` (프론트매터 + 본문 HTML)
- **사진** — `public/images/posts/<slug>/*.webp`
- **데이터베이스 없음.** git 이 이력과 백업을 담당합니다.

## 두 영역으로 나뉩니다

이 저장소는 **공개 영역**과 **편집 영역**이 물리적으로 분리되어 있습니다.
섞이지 않는다는 걸 `npm run verify` 로 언제든 확인할 수 있습니다.

```
heritage-blog/
│
├── 🌐 site/      공개 — 방문자가 보는 사이트.  이것만 빌드되어 배포됨
├── 🔒 studio/    편집 — 나만 쓰는 글쓰기 도구. 절대 배포되지 않음
│
├── 📝 content/   글·댓글 (studio 가 쓰고, site 가 읽음)
├── 🖼  public/    사진  (studio 가 쓰고, site 가 읽음)
└── 🔧 scripts/   도구
```

| | 🌐 site | 🔒 studio |
|---|---|---|
| 누가 보나 | 인터넷의 모든 사람 | 나만, 내 컴퓨터에서만 |
| 실행 | `npm run dev` → :4321 | `npm run studio` → 127.0.0.1:4322 |
| 배포되나 | **예** (`dist/`) | **아니오** |
| 할 수 있는 일 | 읽기만 | 글 쓰기·고치기·사진 올리기 |
| 로그인 | — | 필요 없음 (아래 설명) |

### 왜 편집기에 로그인이 없나

`npm run build` 는 `astro.config.ts` 만 보고, 그 설정의 `srcDir` 은 `site/` 입니다.
`studio/` 는 **별도의 Vite 앱**이라 빌드가 쳐다보지도 않습니다.
그래서 편집 기능은 공개된 사이트에 *존재하지 않습니다*. 지킬 문이 없으니 자물쇠도 필요 없습니다.

편집 서버는 `127.0.0.1` 에만 묶여 있어 같은 와이파이의 다른 기기에서도 열리지 않습니다.

```bash
npm run verify   # dist/ 에 편집기 코드가 섞이지 않았는지 검사
```

이 검사는 `npm run build` 뒤에 **자동으로** 돕니다. 검사에 걸리면 빌드가 실패하므로,
편집 기능이 섞인 결과물은 배포 단계까지 갈 수 없습니다.


## 쓰는 법

```bash
npm run studio   # 편집기 — http://127.0.0.1:4322  (나만)
npm run dev      # 공개 사이트 미리보기 — http://localhost:4321
```

| 명령 | 하는 일 |
|---|---|
| `npm run studio` | 글 쓰기·수정 (Tiptap 편집기, 로컬 전용) |
| `npm run dev` | 공개 사이트 미리보기 |
| `npm run build` | 배포용 정적 파일 생성 (`dist/`) — 끝나면 분리 검사가 자동으로 돕니다 |
| `npm run verify` | 공개/편집 분리가 지켜졌는지 검사 |
| `npm run placeholders` | 샘플 사진 자리 다시 만들기 |

### 글 한 편 쓰는 순서

1. `npm run studio` → **+ 새 글**
2. 맨 위에 **제목을 바로 씁니다.** 파일 이름(주소)은 제목을 따라 자동으로 만들어집니다.
   직접 정하고 싶으면 아래 **글 정보**에서 고치면 됩니다.
3. 바로 아래에 본문을 씁니다. 사진은 **끌어다 놓거나 붙여넣으면** 올라갑니다.
4. 다 쓴 뒤 아래 **글 정보**를 펼쳐 분류와 위치를 채웁니다.
   - `종류`를 `유산`/`전시` 중에 고르면 그에 맞는 칸만 나타납니다.
   - **위치는 지도에서 정합니다.** 이름으로 찾거나 지도를 직접 눌러 찍으면 되고,
     위도·경도를 손으로 입력할 필요가 없습니다. 찾은 주소는 비어 있을 때만 자동으로 채워집니다.
5. `⌘S` 또는 **저장**.
6. 확인되면 `draft` 체크를 풀어 공개합니다.

> 글쓰기 화면은 제목과 본문만 보이게 해 두었습니다.
> 분류·위치 같은 항목은 **글 정보**에 접어두었으니, 쓰는 동안에는 신경 쓰지 않아도 됩니다.

## 이 블로그가 자동으로 해주는 것

프론트매터만 채우면 아래가 따라옵니다. 본문에 다시 적을 필요가 없습니다.

- **정보 박스** — 입장료·운영시간·휴관·지하철·주차·주소를 표로 정리
- **지도** — 편집기에서 위치를 찍으면 `/map/` 과 글 하단 지도에 핀 추가
- **전시 종료 처리** — `exhibition.end` 가 지나면 글 맨 위에 종료 안내가 붙고 목록에서 아래로 내려감
- **색인** — `/heritage/` 에서 종목·시대·지역·박물관별로 자동 분류
- **기준일 안내** — `access.asOf` 를 쓰면 "○○ 기준입니다" 문구가 자동 생성
- 사이트맵 / RSS / JSON-LD 구조화 데이터 / OG 태그

### 변동 정보 관리

유산 자체는 변하지 않지만 **입장료·운영시간·예약 정책은 바뀝니다.**
이것만 바뀌었을 때는 `access.asOf` 날짜만 갱신하세요. 글 전체가 "수정됨"으로 바뀌지 않습니다.

## 사진

편집기에 올리면 자동으로 처리됩니다.

- 가로 1600px 로 축소, WebP(품질 82) 변환
- **EXIF 메타데이터 제거 — 촬영 위치(GPS) 포함**
  여행 사진을 그대로 올리면 집 근처 좌표까지 노출될 수 있어 기본으로 지웁니다.
- `width`/`height` 를 함께 저장해 로딩 중 레이아웃이 밀리지 않습니다
- 툴바의 **⤢ 넓게** 로 본문 폭을 넘기는 전폭 사진으로 바꿀 수 있습니다

## 댓글

방문자는 **로그인 없이** 이름과 내용만으로 댓글을 쓸 수 있습니다.
다만 쓴 즉시 올라가지 않습니다 — 편집기의 **댓글 검토** 에 모이고,
**올리기** 를 눌러야 공개 사이트에 나타납니다.

그래서 이 블로그에 무언가를 올릴 수 있는 사람은 여전히 나 하나입니다.
남이 쓴 글이 내 확인 없이 사이트에 뜨는 일은 없습니다.

| | |
|---|---|
| 저장 위치 | `content/comments/<slug>.json` — 글과 마찬가지로 git 이 이력을 맡습니다 |
| 스팸 방어 | 보이지 않는 미끼 칸(honeypot) · IP 당 10분에 5개 · 같은 내용 연속 차단 |
| 길이 제한 | 이름 20자 · 내용 1000자 |
| 개인정보 | 이메일·비밀번호를 받지 않습니다. IP 도 저장하지 않습니다 |

### 개발 중과 배포 후

| | 댓글 API 가 도는 곳 |
|---|---|
| `npm run dev` | `127.0.0.1:4323` — 개발 서버가 같이 띄웁니다 |
| 배포 후 | 사이트와 같은 주소의 `/api/comments` |

Astro 개발 서버는 자기가 아는 경로만 받기 때문에 개발 중에는 포트를 따로 씁니다.
화면 쪽 코드는 `import.meta.env.DEV` 로 주소만 갈라 쓰고, 빌드하면 개발용 주소는 사라집니다.

> **배포 전에 할 일이 하나 남았습니다.**
> 정적 사이트는 글을 받아 저장할 수 없으므로, 배포 후에는 댓글을 받아줄 자리가 필요합니다.
> Cloudflare Pages 를 쓸 예정이므로 `functions/api/comments.ts` + D1 이 가장 간단합니다.
> 도메인을 정하고 배포할 때 함께 붙이면 됩니다. 그때까지 댓글은 로컬에서만 동작합니다.

## 글을 지웠을 때

편집기의 ✕ 는 영구 삭제가 아니라 `content/.trash/` 로 옮기는 동작입니다.
되살리려면 그 파일을 `content/posts/` 로 옮기면 됩니다.

## 배포

정적 사이트라 아무 데나 올라갑니다. Cloudflare Pages 기준:

| 항목 | 값 |
|---|---|
| 빌드 명령 | `npm run build` |
| 출력 디렉터리 | `dist` |
| Node 버전 | 20 이상 |

### 도메인을 구입한 뒤

`site/consts.ts` 의 `SITE.url` **한 줄만** 바꾸면 됩니다.
사이트맵·RSS·OG 태그·정규 URL 이 모두 그 값을 따라갑니다.

```ts
url: 'https://example.kr',
```

그다음 Google Search Console 과 네이버 서치어드바이저에 등록하고 `/sitemap-index.xml` 을 제출하세요.

## 정확성에 대한 약속

종목·지정번호·명칭은 국가유산청 **국가유산포털**의 공식 표기를 확인해 적습니다.
2024년부터 바뀐 국가유산 체계(문화재 → 국가유산)를 따릅니다.
블로그나 AI 요약을 2차 출처로 쓰지 않습니다.

## 기술 구성

| | |
|---|---|
| 사이트 | Astro 7 (정적 생성, 기본 JS 0) |
| 스타일 | Tailwind CSS 4 |
| 편집기 | Tiptap 3 (React) — 로컬 전용 |
| 지도 | Leaflet + OpenStreetMap (API 키 불필요) |
| 아이콘 | Font Awesome Free — 쓴 아이콘만 SVG 로 인라인 |
| 사진 | sharp |

아이콘은 CDN 전체를 불러오지 않고 **실제 사용한 것만** SVG 로 들어갑니다.
본문에 넣은 아이콘도 글 안에 SVG 로 저장되므로 외부 요청이 없습니다.

### 라이선스 표기

Font Awesome Free 아이콘은 CC BY 4.0 이라 출처 표기가 필요합니다. 푸터에 넣어두었습니다.
지도 타일은 OpenStreetMap 기여자들의 것이며 같은 자리에 표기되어 있습니다.
