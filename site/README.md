# 🌐 site/ — 공개 영역

**방문자가 보는 모든 것이 여기 있습니다.**

이 폴더만 `npm run build` 로 빌드되어 `dist/` 로 나가고, 그 `dist/` 만 배포됩니다.

```
site/
├── pages/          주소가 되는 페이지 (/, /posts/…, /map/, /heritage/, /about/)
├── layouts/        공통 틀 (meta 태그·폰트·테마)
├── components/     조각 (정보 박스, 전시 배지, 지도, 글 카드)
├── lib/            글 읽기·전시 종료 판정·지도 데이터 변환
├── styles/         디자인 토큰과 본문 타이포그래피
├── icons/          직접 만든 SVG 아이콘 (Font Awesome 은 패키지에서 옴)
├── consts.ts       사이트 이름·주소·카테고리  ← 도메인 바꿀 때 여기
└── content.config.ts   글 프론트매터 스키마 (검증 규칙)
```

## 규칙

- **편집 기능을 여기에 두지 마세요.** 글을 고치는 코드가 이 폴더에 들어오는 순간
  그 기능은 인터넷에 공개됩니다. 편집은 전부 `studio/` 에 있습니다.
- 글과 사진은 여기 없습니다. `content/` 와 `public/` 에서 읽어옵니다.
- 바꾸기 전후로 `npm run verify` 를 돌리면 분리가 깨지지 않았는지 확인할 수 있습니다.
